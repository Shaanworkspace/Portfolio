## 🏃 Run Locally

```bash
# Clone the repository
git clone https://github.com/Shaanworkspace/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview
```
